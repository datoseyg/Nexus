## Nota de precisión pedida por la corrección del usuario

Ninguna fila de esta tabla declara un estado "operacional" solo porque el código lo contempla -donde la verificación runtime fue posible (8 de 11 estados), se cita explícitamente; los 3 restantes (`loading` como transición de cliente, y aspectos visuales de `stale`) quedan `NOT_RUNTIME_VERIFIED` con la razón indicada, no se infieren.
